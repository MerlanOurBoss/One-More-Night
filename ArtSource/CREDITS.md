# Third-party models

Keep these lines in the game's credits when it ships.

- **Fridge** (`Assets/Art/Models/Fridge.fbx`, from `ArtSource/Fridge_source.usda`): Articraft Data, Matt Zhou et al.,
  via the sand3d-articraft dataset by Sandflow (https://huggingface.co/datasets/Sandflow/sand3d-articraft),
  CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Modified: parts merged, recoloured, magnets and a note added.
- **Air conditioner, microwave, oven, safe** (`Assets/Art/Models/{Aircon,Microwave,Oven,Safe}.fbx`, from `ArtSource/props_source/`):
  Articraft Data, Matt Zhou et al., via the same dataset and licence. Modified: small parts removed, round parts lowered,
  parts merged, recoloured; a towel and knobs added to the oven, a light to the air conditioner.
- **Washing machine** (`Assets/Art/Models/Washer.fbx`): built with a program from sand3d by Sandflow
  (https://github.com/Sandflow-ai/sand3d), Apache License 2.0. Modified: size-independent circles lowered to 12 sides, recoloured.
